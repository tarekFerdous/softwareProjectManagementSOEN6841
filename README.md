## Course project: SmartHealth

The team project simulated a software project from start to finish. My team produced a feasibility study, solution design and risk plan for **SmartHealth**, a platform with real-time health monitoring and secure data sharing. We used Git for configuration management and Slack to communicate, and applied the course's planning and control tools (WBS, CPM, EVM) to our own schedule.

## Key takeaways

- **Plan with numbers.** Estimate with Function Points or COCOMO, schedule with the Critical Path Method, and track progress with Earned Value Management so overruns show up early.
- **Handle risk before it becomes a problem.** Rank risks by likelihood and impact, then decide whether to accept, avoid, transfer or reduce each one.
- **Pick the lifecycle to suit the requirements.** Waterfall works when scope is stable. Iterative models such as Scrum work when it isn't.
- **Close projects properly.** Archiving and writing down lessons learned is what lets the next project go better.
